# A Rust application based on cdda2img

      The "8 tracks" of this program are as follows:

      1. Rip - CD Audio discs to FLAC + CUE files
      2. Archive - CD Audio discs, or audio files in many formats, to RBI files
      3. Catalogue - CD Audio disc collection
      4. Extract - RBI files to TOC + FLAC files
      5. Remaster - Trim silence, and normalise tracks (hardcoded or ReplayGain)
      6. Convert - Many CD Audio disc image formats to RBI
      7. Play - CD Audio discs, RBI images, or extracted FLAC files
      8. Burn - RBI files to CD Audio discs
